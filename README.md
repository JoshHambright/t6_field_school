# T6 Field School

A guided course for getting off Auto on the Canon EOS Rebel T6 (EOS 1300D).

**Live site:** https://joshhambright.github.io/t6_field_school/

## What's inside

- **Learn**: ten lessons in order, from leaving A+ to full manual. Each one has a short explanation, coached step-by-step practice in the simulator, exercises for the real camera, and a quick quiz.
- **Simulator**: a practice camera with the T6's mode dial, main dial, Av± and ISO buttons, a viewfinder meter, and a histogram. Aperture, zoom, shutter speed, ISO, white balance and metering all change the simulated photo. Includes 12 challenges with star ratings.
- **Drills**: a 60-second quiz on stop math, mode choice and T6 controls.
- **T6 Field Guide**: the mode dial, a map of the controls, how-to recipes, a scene-mode translator and the specs that matter.
- **Cheat Sheets**: short reference cards, an equivalent-exposure calculator and the Frame It composition game.
- **Missions & Badges**: real-world assignments with notes, XP and badges.

Progress is saved in your browser's local storage, so it stays on that device and browser.

## Running locally

It's one static file with no build step. Open `index.html` in a browser, or serve the folder:

```bash
python -m http.server 8000
```

Fonts load from Google Fonts. Everything else is inline.

## Notes

This is an unofficial study tool, not affiliated with Canon. The simulation is simplified so the lessons are visible on screen. Check the camera's manual for anything critical.
